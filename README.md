## 先定计费方式：包年包月、按量付费还是抢占式实例

长期稳定的业务选包年包月，波动大或短期使用选按量付费，能接受随时被回收的任务选抢占式实例。计费方式决定了同一台机器最终花多少钱，建议在选配置之前先定下来。

| 付费类型 | 计费规则 | 适合场景 | 注意点 |

| 包年包月 | 先付费后使用，最短可按周购买 | 7×24的Web服务、数据库等长期业务 | 平均成本最低 |
| 按量付费 | 先使用后付费，计费精确到秒 | 临时扩展、测试、电商抢购 | 开通时账户现金余额加代金券总值不能低于100元 |

## 带宽和系统盘：1M到底够不够用

1M固定带宽的下载速度是128KB/秒。纯文字站、低流量博客够用；图片多、有文件下载的站就紧张，好在带宽是少数可以后期单独升降配的资源。

带宽计费分两种：按固定带宽，先买断一个带宽值，北京地域1M约23元/月；按使用流量，北京地域0.8元/GB，先用量后付费。判断方法很简单：带宽利用率低于10%选按流量，实际利用率高就选固定带宽。如果网站接了CDN和对象存储OSS，源站流量很小，1M固定带宽基本够。

系统盘默认40GiB，最低容量跟镜像走：Linux最低20GiB起，Windows和Red Hat要40GiB起，上限都是2048GiB。云盘类型有ESSD Entry、ESSD、ESSD AutoPL、SSD云盘和高效云盘，个人用途选40G的ESSD Entry就行。数据盘可以不买，实例创建后随时能挂载。

快照服务免费开通，按实际存储容量收费，普通快照0.12元/GB/月。建议下单时顺手设一个自动快照策略，遇到误删数据或中毒，这是最便宜的保险。
